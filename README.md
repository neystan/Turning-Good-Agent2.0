# Turning-Good-Agent 2.0

一个只需要跟它说话的通用个人助手（personal agent）：它记得、它整理、它提醒，复杂的处理都在后台完成。

## 设计方向

- **单一会话**：用户不需要管理会话，不同话题由系统在后台自动分类。
- **重记忆、轻会话**：多层记忆，上下文压缩对用户无感，长期使用也不会膨胀。
- **多层主动提醒**：不只是任务完成后汇报，还会总结日常、提醒需要注意的事。
- **全天候运行**：runtime 常驻在云端，桌面端和手机端只是接入渠道，关掉它们不影响系统运行。
- **内核极小**：内核只保留最基本的部分，其余能力以插件形式接入。

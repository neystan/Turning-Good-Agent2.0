## MVP 路线

每一步都要能独立运行。开始某一步之前，先在 `docs/phases/` 下写阶段文档并经所有者确认。

| 步骤 | 内容 | 验证方式 | 状态 |
| --- | --- | --- | --- |
| M1 | 最简单的 runtime：消息进来 → 记录原始日志 → 按状态组装上下文 → agent loop → 回复 | 能连续对话；上下文始终在预算内 | 未开始 |
| M2 | 核心档案：后台提取，写入前与已有事实比对 | 聊几天后能准确说出关于用户的关键事实 | 未开始 |
| M3 | 承诺：创建、去重、状态流转、到点前核实后提醒 | 交代 20 件事，无遗漏、无重复、不提醒已完成的事 | 未开始 |
| M4 | 时间线：每日日记、早间简报、晚间回顾 | 连续一周，日记与实际一致 | 未开始 |
| M5 | 检索与话题：混合检索、翻记录工具、话题分配 | 测试集召回率达标；交替聊多个话题不混淆 | 未开始 |

M1 之后各步骤的顺序和内容会在 M1 完成后重新确认。
